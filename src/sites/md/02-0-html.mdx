## Webseiten

Eine Webseite ist ein Dokument das von Ihrem Webbrowser dargestellt wird. Die
Strukturierung des Dokuments wird mit **HTML** gemacht. Dies ist eine einfache
Art dem Computer zu sagen welche Teile zusammen gehören, und von welchem Typ
diese Teile sind.

### Überschriften

<section>

Möchten wir einen Text als **Überschrift** festlegen, machen wir das in

**HTML** mit der folgenden Syntax:

```html
<h1>Überschrift</h1>
```

Mit `<h1>` sagen Sie dem Computer dass nun eine Überschrift folgt. Dann wird all
der Text bis `</h1>` als Titel interpretiert.

Neben `<h1>` gibt es auch kleinere Überschriften `<h2>`, `<h3>`, ..., `<h6>`.
Versuchen Sie auch diese in Ihr Dokument zu integrieren.

Neben der Überschrift, gibt es noch viele andere **HTML Elemente**. Einige
wichtige werden hier besprochen, eine ausführlichere Liste kann auf

<a href="https://www.w3schools.com/html/default.asp">w3schools</a> gefunden werden.

</section>

### Abschnitt

<section>

Um in **HTML** einen Abschnitt zu machen, brauchen Sie das `<p>`-Tag. Alles was
darin ist, wird als Abschnitt betrachtet. **HTML** ignoriert Zeilenumbrüche und
mehrfache Leerzeichen um Dokumente konsistent anzuzeigen. Damit Sie Abschnitte
verwenden können, brauchen Sie also `<p>`.

```html
<p>Hier steht ein Textabschnitt, welcher auf Ihrer Webseite auftauchen wird.</p>
```

</section>

### Listen

<section>

In **HTML** gibt es zwei Arten von Listen. Ungeordnete Listen `<ul>` und
geordnete Listen `<ol>`. Innerhalb einer Liste ist jedes Element ein
Listeneintrag. Der folgende Code erstellt Ihnen eine Liste.

```html
<ul>
  <li>Eintrag eins</li>
  <li>Eintrag zwei</li>
</ul>
```

Versuchen Sie neue Einträge hinzuzufügen, und ändern Sie die Liste in eine
geordnete Liste.

</section>
